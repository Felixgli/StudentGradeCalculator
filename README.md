# Student Grade Calculator 🎓

## 📌 About the Project

The Student Grade Calculator is a beginner-friendly C++ console application designed to calculate a student's average score and determine their grade based on their performance.

This project was developed as part of my journey as an IT student to improve my programming skills and practical understanding of C++.

## ✨ Features

- Accepts student scores as input.
- Calculates the average score.
- Determines the student's grade.
- Displays the result clearly to the user.

## 🛠️ Technologies Used

- Programming Language: C++
- IDE: Code::Blocks
- Version Control: Git
- Repository Hosting: GitHub

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project in Code::Blocks.
3. Build and run the program.
4. Enter the required student scores.
5. View the calculated average and grade.
